## Новая структура

```
instructions.md                    # Обзор проекта + ссылки на подзадачи
docs/
├── frontend.md                    # Дизайн фронта, компоненты, стили
├── admin.md                       # Авторизация, дашборд, пользователи
├── database.md                    # Схема БД, миграции
├── spreads.md                     # Обзорная дока по раскладам (ссылки на JSON)
└── compose/                       # Спеки и планы (оставляем как есть)
backend/prompts/
├── persona.md                     # Персона LLM (без изменений)
└── spreads/
    ├── one-card.json              # Расклад "Одна карта" (без изменений)
    └── one-card.md                # Промпт расклада (без изменений)
```

## Что создаём

### 1. `docs/frontend.md`
Описание архитектуры фронта:
- Компоненты и их responsibilities
- Роутинг (экраны: login → onboarding → dashboard → reading → history)
- Нижнее меню (BottomNav)
- Стили и тема (Almendra, Babylonica, палитра)
- Структура файлов в `frontend/src/`

### 2. `docs/admin.md`
Логика админки/пользователя:
- Авторизация (Telegram initData + login/password)
- Регистрация (флоу: логин/пароль → имя/пол → дашборд)
- Дашборд пользователя
- История раскладов

### 3. `docs/database.md`
Схема БД:
- Таблицы: users, tarot_sessions, reading_cycles, system_config
- Миграции (Alembic)
- Связи между таблицами

### 4. `docs/spreads.md`
Обзор раскладов:
- Как добавить новый расклад
- Структура JSON-конфига
- Ссылки на `backend/prompts/spreads/`

### 5. `instructions.md` (обновить)
Добавить ссылки на поддоки:
```markdown
## Документация
- [Дизайн фронта](docs/frontend.md)
- [Авторизация и пользователи](docs/admin.md)
- [База данных](docs/database.md)
- [Расклады](docs/spreads.md)
```
