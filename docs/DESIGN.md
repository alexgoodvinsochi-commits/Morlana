# Design System — Morlana

Правила оформления дизайна фронтенда. Каждая страница собирается по этим принципам.

---

## 1. Reading Screen — Карта расклада

### Размер карты
- Карта занимает **3/4 высоты экрана** (~75vh)
- Минимальный размер: 280×467px (отношение сторон 3:5)

### Позиционирование
- Карта центрирована по горизонтали
- Отступ сверху: 20px
- Отступ снизу: оставшееся пространство для текста

### Толкование (текст LLM)
- Расположен **под картой**, перекрывает нижнюю часть карты
- Фон: прозрачная подложка с градиентом
  - От середины вверх: `transparent` → `rgba(10, 6, 18, 0.9)`
  - От середины вниз: `transparent` → `rgba(10, 6, 18, 0.9)`
- Текст **скроллируется вертикально** внутри контейнера
- Максимальная высота текстового блока: 40% экрана

### Анимация появления карты
- Карта появляется **справа** (translateX: 100% → 0)
- Длительность: 400ms, ease-out
- При появлении — haptic feedback (после MVP)

### Горизонтальный свайп
- Карты можно **свайпать горизонтально** (left/right)
- Свайп влево = показать следующую карту (если есть)
- Свайп вправо = показать предыдущую карту
- Индикатор: точки внизу (как в галерее)
